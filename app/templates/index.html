Sobre o SpaceDebris Tracker

O SpaceDebris Tracker é uma plataforma integrada de monitoramento, análise e predição de risco causado por detritos espaciais em órbita terrestre. A solução foi desenvolvida como parte da Global Solution 2026 da FIAP, no desafio temático Indústria Espacial: O Código que Move o Universo.

Existem hoje mais de 27.000 detritos orbitais rastreados e estima-se mais de 1 milhão de fragmentos menores que 10 cm em órbita. A colisão com detritos representa uma ameaça direta a satélites operacionais, à Estação Espacial Internacional (ISS) e às futuras missões espaciais. O custo médio de um satélite perdido supera US$ 300 milhões — e sistemas de monitoramento acessíveis e preditivos ainda são escassos para pequenas empresas e pesquisadores independentes.

Nossa solução combina dados orbitais de APIs públicas (NASA, CelesTrak, N2YO), machine learning para predição de colisões, visão computacional para classificação de cobertura de solo por satélite, um pipeline de dados automatizado com Apache Airflow e uma infraestrutura cloud segura no Microsoft Azure — tudo integrado em um painel público de monitoramento em tempo real.

A plataforma é construída seguindo práticas de DevSecOps: infraestrutura como código com Terraform, pipeline CI/CD automatizado via GitHub Actions, credenciais protegidas no Azure Key Vault, HTTPS ativo e monitoramento contínuo com Application Insights.

Machine Learning

Predição de nível de risco de colisão usando Random Forest e XGBoost com interpretabilidade SHAP.

Visão Computacional

CNNs treinadas do zero para classificar cobertura de solo em imagens satelitais com Gradio.

Pipeline de Dados

DAGs no Apache Airflow ingerindo dados orbitais reais e armazenando no Oracle DB da FIAP.

Cloud & DevSecOps

Azure App Service, Key Vault, Application Insights e CI/CD automatizado via GitHub Actions.

Automação RPA

Bot UiPath monitorando dados espaciais, aplicando regras de negócio e enviando alertas.
